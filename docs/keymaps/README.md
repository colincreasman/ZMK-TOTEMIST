# Experimental keymaps

These are Totemist adaptations of the two Toucan keymap experiments. Both keep
the Totemist home-row-mod timings, Escape combos, and maintenance layer.

The right bottom pinky switch is broken, so slash stays on the right home-row
pinky (`/` tap, Shift hold), and backslash is on that key in L1.

- **v1:** Enter is on L1+A. See [SVG](experiment-v1.svg) or [PNG](experiment-v1.png).
- **v2:** Enter is `Z+X` or `,+.` on L0, with a 25ms timeout. L1+A is `_`.
  The right combo uses `,+.` because the Toucan's `.+/` switch is broken here.
  See [SVG](experiment-v2.svg) or [PNG](experiment-v2.png).

Both use L1 for `1`–`0` along Q–P and HJKL arrows. Left middle thumb is an
immediate L1 key; right inner thumb remains Space/L1. The far outer thumbs
still activate the maintenance layer together.
